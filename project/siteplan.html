# Bird Migration Tracker - Site Plan ## Site Name ### Bird Migration Tracker **Reason for Selection:** This name clearly describes the purpose of the website. Visitors will immediately understand that the site focuses on tracking bird migrations, learning about migration routes, and exploring information about different bird species. **Optional Domain Availability:** birdmigrationtracker.org --- ## Site Purpose The Bird Migration Tracker website provides educational information about bird migration patterns around the world. Visitors can explore migration routes through interactive maps, learn about different bird species, discover migration seasons, understand how weather affects migration, and find information about bird conservation efforts. The site aims to help users learn more about bird behavior while providing engaging and interactive content. --- ## Scenarios ### Scenario 1 When do birds begin migrating through my area each year? ### Scenario 2 How does weather affect bird migration routes and travel times? ### Scenario 3 Which bird species migrate the farthest distances? ### Scenario 4 What conservation efforts help protect migratory birds? --- ## Color Schema ### Sky Blue (#4A90E2) **Used for:** * Header background * Navigation bar * Section headings * Buttons and links ### Forest Green (#2E8B57) **Used for:** * Accent elements * Icons * Borders * Highlights and callout sections ### Light Gray (#F4F4F4) **Used for:** * Page background * Content section backgrounds ### Dark Gray (#333333) **Used for:** * Body text * Footer text --- ## Typography ### Roboto **Used for:** * Body text * Paragraphs * Navigation links ### Merriweather **Used for:** * Main headings (H1, H2, H3) * Section titles ### Open Sans **Used for:** * Captions * Supplemental information * Form labels --- ## Wireframes ### Mobile View --- | LOGO | | Bird Migration Tracker | ------------------------------------------------ ## | Navigation Menu | ## | Hero Image/Banner | ## | Welcome Section | ## | Featured Migration Map | ## | Bird Species Profiles | ## | Weather & Migration Info | ## | Footer | ### Desktop View --- ## | LOGO Bird Migration Tracker Navigation Menu | ## | Hero Image/Banner | ## | Welcome Section | ## | Migration Map | Species Profiles | ## | Weather Information | Conservation Info | ## | Footer |
